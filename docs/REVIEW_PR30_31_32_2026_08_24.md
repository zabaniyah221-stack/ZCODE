## 7. Addendum (sesi arena/01a03332-zcode, 2026-08-25)

Ditambahkan oleh sesi implementasi pasca-v1.0.21. Addendum ini **tidak mengubah
vonis** di atas; ia mempertegas bukti untuk PR #31 dan mendokumentasikan alasan

### 7.1 PR #31 — `rename_symbol` ternyata tidak pernah memakai rope

Bukti tambahan (baca langsung `app/src/main/python/editor/rope_layer.py` di
head `8775958`, 82 baris): `rename_symbol()` memanggil
`self._safe_replace_symbol(code, old_name, new_name)` **juga di jalur sukses**
— bukan hanya di blok `except`. `rope.refactor.rename` di-import tetapi tidak
pernah dipakai untuk refactoring apa pun. `_safe_replace_symbol` sendiri adalah
regex plain `\b<old>\b → <new>` atas seluruh source, sehingga **mengganti nama
di dalam string literal dan komentar** — padahal docstring-nya mengklaim
"AST/Token-based safe symbol replacement". Ini melanggar kontrak rename
fail-closed v1.0.21 (release notes: "Rename Symbol tidak lagi mengganti
string/comment dan menolak kasus yang belum dapat ditransformasi dengan aman").

Konsekuensi untuk syarat merge (mempertegas syarat #1 di §3): `rename_symbol`
harus memanggil `rope.refactor.rename.Rename(...).get_changes(...)` sungguhan,
dan bila `get_changes` gagal/kosong → **tidak ada perubahan apa pun**
(fail-closed), bukan fallback regex.

### 7.2 PR #32 — audit rangkuman sesi penulis (KAI 9000)

Rangkuman sesi yang menyertai PR #32 memuat klaim yang tidak mungkin benar
(halusinasi). Ini konteks mengapa body PR #32 tidak dipercaya (temuan
sistemik #4 di §1):

- "Intelligence Spike (**deteksi spike via kamera**)" — aplikasi ini tidak
  memiliki fitur kamera;
- rencana versi salah: "v1.0.22 = tombol upgrade di sidebar, v1.0.23 = testing
  upgrade" — bertentangan dengan roadmap resmi (v1.0.22 = verified one-tap
  update, engine intelligence adalah item terpisah);
- usulan workflow GitHub memakai `actions/checkout@v4` dan
  `softprops/action-gh-release@v1` (tag, bukan full-SHA) — melanggar pin
  full-SHA + manual-dispatch yang dijaga guard repo;
- `if (newVersion <= currentVersion) throw SecurityException(...)` memakai
  perbandingan **string** versi — kelas bug yang sama dengan yang sudah
  dimakamkan guard v1.0.21 (bandingkan angka per segmen: `1.0.10 > 1.0.9`);
- "App Lockdown: mencegah shutdown selama update" — tidak mungkin pada
  Android (proses dapat dibunuh sistem kapan pun);
- "TOOLS: Eksekusi shell tools via os.system()", "DIAGNOSTICS: Debug Mode via
  adb/reverse_tcp" — di luar kontrak aplikasi.

Tidak satu pun klaim di atas diverifikasi dengan bukti.
